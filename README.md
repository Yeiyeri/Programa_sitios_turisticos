# ExploraGuajira

Aplicacion de consola desarrollada en Python para consultar sitios de interes turistico, natural, popular e historico.

## Funcionalidades de esta primera version

- Mostrar todos los sitios turisticos registrados.
- Consultar los detalles de un sitio.
- Filtrar sitios por tipo: natural, historico o popular.
- Salir del programa desde un menu.

Los datos se almacenan en una lista de diccionarios dentro de `sitios_turisticos.py`. El archivo `main.py` contiene las funciones y el menu principal.

## Requisitos

- Python 3 instalado.
- No se necesitan librerias externas.

## Como ejecutar

Abre una terminal en la carpeta del proyecto y ejecuta:

```bash
python main.py
```
